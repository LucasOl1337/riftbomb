# grokimagineassets

Pilha de **opções** Imagine para peneira. **Tudo na raiz** — não tem subpasta de aspecto.

## Nome do arquivo

`{aspecto}_{NN}_{slug}.jpg`

Exemplos:
- `ground_07_riverbed-sand-mud.jpg`
- `wall-side_03_hextech-metal-panels.jpg`
- `floor-tile_01_hex-tile-dark.jpg`

O prefixo (`ground_`, `wall-side_`, `wall-top_`, `floor-tile_`, `lane_`, `river_`, `stone-turret_`) diz o que é. Ordena por nome no Explorer.

## Meta

`_meta/catalog.json` — lista planejada de 50 por aspecto  
`_meta/progress.json` — contagem (geração parada a pedido)

## Qualidade

Régua: `game/art/ART-QUALITY.md`. Native Imagine, sem upscale. Nada daqui entra no jogo até você promover.
